# 🇧🇩 বইবন্ধু AI (BoiBondhu AI) & বুকশপ B2B SaaS ইঞ্জিন

বাংলাদেশের ১৭টি শীর্ষস্থানীয় অনলাইন বইয়ের দোকান থেকে রিয়েল-টাইম স্ক্র্যাপিং করে **সবচেয়ে কম দাম** ও **স্টক** বের করার ইঞ্জিন এবং যেকোনো অনলাইন বুকশপ বা ফেসবুক পেজে সেলস বাড়ানোর জন্য **B2B এআই সেলসম্যান SaaS সলিউশন**।

---

## 💼 B2B SaaS মডেল (অনলাইন বুকশপের কাছে ৳১,৫০০ - ৳২,৫০০/মাস সাবস্ক্রিপশনে বিক্রির নিয়ম)

যেকোনো অনলাইন বুকশপ বা ফেসবুক পেজ মালিকদের কাছে এই সার্ভিসটি বিক্রি করার জন্য সম্পূর্ণ **মাল্টি-টেন্যান্ট ও সিঙ্গেল-স্টোর এক্সক্লুসিভ আর্কিটেকচার** তৈরি করা হয়েছে:

### ১. সিঙ্গেল-স্টোর এক্সক্লুসিভ মোড (Store-Exclusive Mode):
- যখন কোনো নির্দিষ্ট ক্লায়েন্ট কোম্পানি (যেমন: **রূহামা শপ** বা **আলাদা বই**) আপনার কাছ থেকে বটটি সাবস্ক্রাইব করবে, তখন তাদের ওয়েবসাইটের উইজেট এবং ফেসবুক পেজের বট **শুধুমাত্র তাদের স্টোরের বই ও স্টক** দেখাবে।
- **কোনো প্রতিদ্বন্দ্বী দোকানের নাম, দাম বা লিংক কখনোই আসবে না!**
- তাদের সাইটে স্ক্রিপ্ট বসানোর নিয়ম (মাত্র ১ লাইন):
  ```html
  <!-- রূহামা শপের জন্য -->
  <script src="https://yourdomain.com/widget.js" data-merchant="ruhama" async></script>

  <!-- আলাদা বই-এর জন্য -->
  <script src="https://yourdomain.com/widget.js" data-merchant="aladaboi" async></script>

  <!-- বাতিঘরের জন্য -->
  <script src="https://yourdomain.com/widget.js" data-merchant="baatighar" async></script>
  ```

### ২. ফেসবুক পেজ মেসেঞ্জার ইনবক্স অটোমেশন (Pro Omni Plan):
বাংলাদেশে ৮০% এর বেশি বই ফেসবুক পেজের মেসেঞ্জারে বিক্রি হয়। ক্লায়েন্টের ফেসবুক পেজে এই বট কানেক্ট করার জন্য:
- **Webhook URL:** `https://yourdomain.com/api/webhook/facebook?merchant=ruhama`
- **Verify Token:** `boibondhu_webhook_token`
- ফেসবুক ইনবক্সে কাস্টমার নক দিয়ে কোনো বই বা বিষয়ের কথা বললেই বট স্বয়ংক্রিয়ভাবে ওই স্টোরের বই, লাইভ স্টক ও অর্ডার লিংক পাঠিয়ে সেলস ক্লোজ করবে।

### ৩. প্রাইসিং ও প্যাকেজসমূহ:
- **Standard Web Plan (৳১,৫০০/মাস):**  
  ওয়েবসাইটে ১ লাইনের চ্যাট উইজেট স্ক্রিপ্ট + সিঙ্গেল স্টোর এক্সক্লুসিভ মোড + হোয়াইট-লেবেল ব্র্যান্ডিং + ২,০০০ কনভারসেশন/মাস।
- **Pro Omni Plan (৳২,৫০০/মাস):**  
  Standard Plan + **ফেসবুক পেজ মেসেঞ্জার বট ইন্টিগ্রেশন** + ক্যাশ-অন-ডেলিভারি ডিরেক্ট অর্ডার কালেকশন + আনলিমিটেড কনভারসেশন + কাস্টমার ইনটেন্ট অ্যানালিটিক্স।

## 🚀 কীভাবে চালাবেন (How to Run)

প্রজেক্ট ফোল্ডারে টার্মিনাল খুলে কমান্ড দিন:

```bash
cd "c:\Automation_project\on time book data scraping"
uv run --with requests,beautifulsoup4,flask python app.py
```
*(অথবা সাধারণ পাইথনে: `python app.py`)*

সার্ভার চালু হলে ব্রাউজারে প্রবেশ করুন:
- **B2B SaaS মার্চেন্ট পোর্টাল ও সিমুলেটর:** [http://localhost:5000/merchant](http://localhost:5000/merchant)
- **মেইন প্রাইস কম্প্যারেটর ও উইজেট:** [http://localhost:5000/](http://localhost:5000/)
- **ফুলস্ক্রিন এআই সেলসম্যান পেজ:** [http://localhost:5000/salesman](http://localhost:5000/salesman)
- **মাল্টি-মার্চেন্ট উইজেট ডেমো:** [demo_widget.html](file:///c:/Automation_project/on%20time%20book%20data%20scraping/demo_widget.html)
